# Peekr

Peekr is a zero-cost AI browser automation assistant powered by free vision models.

## Current Status

**Phase 1: Project Scaffold & Extension Shell — ✅ Complete**

The basic scaffolding of a loadable Chrome extension with a side panel is in place. It uses:
- React
- Vite
- Tailwind CSS
- CRXJS Vite Plugin (for building the Chrome extension)

## Development Setup

1. **Install Dependencies:**
   ```bash
   npm install
   ```
2. **Generate Placeholder Icons:**
   ```bash
   npm run generate-icons
   ```
3. **Build the Extension:**
   ```bash
   npm run build
   ```
4. **Load into Chrome:**
   - Go to `chrome://extensions/`
   - Enable **Developer mode**
   - Click **Load unpacked**
   - Select the `dist/` directory generated by the build step.
5. **Start Dev Server (Watch Mode):**
   ```bash
   npm run dev
   ```
   *(Note: After modifying code in dev mode, you may need to go to the extensions page and click the refresh icon on the Peekr extension to see changes in the background script, though Vite handles HMR for the UI.)*
